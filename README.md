# Audio Loader Explanation

Audio Loader is a Decky plugin for Steam Deck which allows you to download sound packs and BGM. Sound packs replace the SteamUI sounds for custom ones made by people at DeckThemes.com, as well as BGMs.
Decky is a homebrew modding application for Steam Deck. Download it from their site and run it in Steam Deck's Desktop Mode. After that, going into your quick menu, you can see a small plugin icon. You can download cool plugins that way.

# What this pack contains

This pack contains Player sounds and UI sounds from R.E.P.O. Jumping sounds, extraction point sounds, all of that.
